# TXT添付中の入力欄安定確認

実51ツール（TXT 81,327 bytes、本文1,266～1,267文字）で同じ限定read_file課題を修正前後3回ずつ実M365 / Think Deeperへ送信。すべてパス・開始行・終了行の厳密照合に成功。業務ツールは実行せず、ツール呼び出し応答の搬送時間を測った。

| 項目 | 修正前 | 修正後 |
| --- | --- | --- |
| 全体ms（3回） | 15984, 16081, 30709 | 15435, 13372, 14606 |
| 添付後の追加安定待ちms | 1051, 1039, 1047 | 2, 1, 1 |
| TXT添付ms | 3452, 4607, 2267 | 3376, 2621, 2482 |
| 応答待ちms（終了確認込み） | 7714, 7553, 24166 | 9063, 7547, 9071 |

添付完了をポーリングする同じループで、既存のeditorReadyを呼ぶ。空・有効・同じ入力ノード・同じ要求IDの安定時間1000msは変更しない。添付終了後も再確認し、入力ノードが置換されたら時間を取り直す。入力全文照合、モデル確認、添付確認、応答安定待ち、厳密応答解析は保持。

全体中央値は16.081秒から14.606秒だが、M365応答に大きなばらつきがあり、3回ずつの逐次比較で一般的な速度向上を証明するものではない。直接確認できた改善は、添付後に重複していた約1秒の追加待ちの解消。VS Code経由の複数工程や会社テナントを示す試験ではない。
