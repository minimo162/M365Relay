# PDF解析のプロセス分離

PDFコマンドのネイティブ解析を子プロセスに分離。親は120秒の期限を持ち、子の異常終了や中止を失敗として返す。結果が届いても子の正常終了までは出力しない。これは解析コマンドの停止・復旧対策で、従来もRelayサーバー自身がPDFを解析していたわけではない。

JSON出力は最大32MiB。読み取り範囲を小さくして処理できる。完成データを出力先と同じディレクトリの一時ファイルへ書き、排他的なハードリンクで公開する。既存出力や途中で作られた同名出力を上書きしない。NTFS等のハードリンク対応ファイルシステムが必要で、対応しない保存先では失敗するためローカル作業フォルダーを使用する。中止時の一時ファイルは削除する（親プロセスの強制終了・OS終了は除く）。

合成子プロセスで正常終了、結果送信後の異常終了、同期無限ループのタイムアウト、キャンセル、不正結果を確認。出力試験では既存ファイル保全とキャンセル時の一時ファイル削除を確認。実PDFの配布ランタイム検証は別に実施する。

実機検証: 同梱Node 22.23.2 / LiteParse 2.14.4で日本語201ページPDFを全ページ解析し、公開0.2.17のJSONと全体がdeepEqual一致。71～72ページ指定も全体結果の該当ページと一致。72ページの10,600 / 8,100 / 4,200 / 537と座標を保持。原本SHA256は不変。全体出力1,639,996 bytes、ウォーム状態の一回の実測579ms（一般的な速度保証ではない）。145テストと実配布ZIPの9検査が成功。VS Codeエージェントからの全工程は未検証。
